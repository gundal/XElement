# Pre-publish checklist

Before any future public update:

- [ ] No source copied from private employer repositories.
- [ ] No employer namespaces, internal class names, selectors or business workflows.
- [ ] No internal URLs, hostnames, environment names or customer identifiers.
- [ ] No credentials, tokens, secrets or configuration values.
- [ ] Synthetic examples only.
- [ ] Historical claims clearly separated from behavior of the public reconstruction.
- [ ] Any new architecture description is supported by the historical design or clearly labeled as a modern redesign.
- [ ] Build passes in GitHub Actions.
