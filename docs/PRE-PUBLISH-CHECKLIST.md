# Pre-publish checklist

Before adding any historical material to this public repository:

- [ ] Confirm the file contains no credentials, tokens, passwords or private keys.
- [ ] Remove personal/customer/employer email addresses that are not necessary to the architecture.
- [ ] Remove internal hostnames, IPs, environment URLs and infrastructure identifiers.
- [ ] Replace employer-specific namespaces/application names when they add no architectural value.
- [ ] Remove customer-specific workflows, data models and page selectors.
- [ ] Do not publish binaries or historical configuration files.
- [ ] Verify third-party helper provenance before copying source.
- [ ] Prefer a new implementation when provenance is uncertain.
- [ ] Preserve important architecture/method semantics rather than simplifying them away.
- [ ] Build the public project and examples successfully before treating a revision as complete.
